# Midscene
This connector bundles @midscene/web and @midscene/shared 1.12.4.
The official ExtensionBridgePageBrowserSide implements actions, input, screenshots and the Bridge protocol. Testo only adds local pairing, a profile installation identifier, an all-window tab catalog and explicit window focus.
Upstream: https://github.com/web-infra-dev/midscene/tree/v1.12.4

No Chrome profile names, cookies or profile directories are copied.
